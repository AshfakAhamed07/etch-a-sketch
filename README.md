# Etch-a-Sketch

A browser-based Etch-a-Sketch project built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## Live Demo

**[View the Etch-a-Sketch](https://ashfakahamed07.github.io/etch-a-sketch/)**

## Features

* Generates a default 16 × 16 grid.
* Dynamically creates grid squares using JavaScript.
* Uses Flexbox to arrange the grid.
* Hover over squares to change their color.
* Generates a random RGB color on each interaction.
* Gradually darkens each square over repeated interactions.
* Squares become fully dark after 10 interactions.
* Allows users to choose a new grid size through a prompt.
* Supports grid sizes from 1 × 1 up to 100 × 100.
* Validates user input and handles cancelled prompts.
* Keeps the grid within the same overall space when changing its size.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Flexbox

## How to Use

1. Open the project in your browser.
2. Hover over the grid squares to interact with them.
3. Each interaction changes the square's color and gradually darkens it.
4. Click **New Grid** to create a different grid size.
5. Enter a number between `1` and `100`.
